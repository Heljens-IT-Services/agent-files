# STRUCTURE.md

Stand: April 2026

## Zweck

Orientierung fuer Menschen und AI Agents. Diese Datei ist ein dauerhaft zu pflegender Index der wichtigen Dateien, Klassen, Typen, Services, Logiken und Tests im Repository.

## Index

Die Spalte Pfad beschreibt den Repository-Pfad inkl. Dateinamen.
Die Spalte Typ meint in codebasierten Dateien den Klassen- bzw. Objektnamen. In anders gearteten Dateien kann die Spalte Typ durchaus als Ort für ein Stichwort dienen. Und Zweck meint hier eine Beschreibung der Datei in maximal einem Satz.

| Pfad | Typ | Zweck |
|---|---|---|
| `README.md` | Schnelleinstieg | Liefert den kompakten Einstieg in das Repository. |
| `AGENTS.md` | Agent-Regeln | Arbeitsregeln fuer AI-/Code-Agents im Projekt. |
| `agents/STRUCTURE.md` | Strukturindex | Beschreibt die aktuelle Repository-Struktur. |
| `agents/PROJECT.md` | Projektinformation | Enthält projektspezifische Regeln, Fakten, sowie Domänwissen. |
| `agents/DEVELOPER.md` | Architektur / Coding | Definiert allgemeine Entwicklungsregeln für dieses Repository. |
| `agents/DEVELOPER.*.md` | Technologieregeln | Ergänzt technologie- oder kontextspezifische Entwicklerregeln. |
