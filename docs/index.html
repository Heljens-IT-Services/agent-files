Heljens Agent Files

Diese GitHub Page ist die verbindliche Single Source of Truth fuer die aktuell veroeffentlichten Agent- und Developer-Anweisungen von Heljens IT Services.

Andere Repositories und Projekte sollen auf diese Seite verweisen, wenn sie die gueltigen Arbeitsanweisungen fuer KI-Agenten, Codex oder vergleichbare Entwicklungsassistenten referenzieren.

Zu den Dateien Ueberblick

Verbindlichkeit

Zentrale Referenz fuer aktuelle Agent- und Developer-Anweisungen

Diese Seite stellt den aktuellen verbindlichen Stand der Agent- und Developer-Anweisungen von Heljens IT Services bereit. Aenderungen werden im Repository gepflegt und anschliessend nach docs/ veroeffentlicht.

Single Source of Truth

Die eigentlichen Quelldateien liegen im Repository unter files/. Die GitHub Page zeigt den aktuell veroeffentlichten Stand dieser Inhalte.

Referenzierbar

Andere Repositories muessen nur noch auf https://heljens-it-services.github.io/agent-files/ verweisen.

Nachvollziehbare Pflege

Die veroeffentlichten HTML-Seiten werden aus den Markdown-Quelldateien erzeugt, damit keine zweite manuell gepflegte Version entsteht.

Pflegeprozess

Quelle im Repository, Ausgabe unter docs/

files/
  AGENTS.md
  agents/
docs/
  index.html
  reference/
scripts/
  sync-docs.ps1

Inhaltliche Aenderungen erfolgen ausschliesslich in den Markdown-Dateien unter files/. Das Script scripts/sync-docs.ps1 erzeugt daraus die veroeffentlichten Referenzseiten unter docs/reference/.

Dadurch bleibt die Website lesbar und referenzierbar, ohne dass dieselben Anweisungen an zwei Stellen manuell gepflegt werden muessen.
