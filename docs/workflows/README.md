# Workflows

Diese Dateien beschreiben zusammengesetzte Agentenablaeufe.

Ein Workflow:
- verfolgt ein groesseres Ziel,
- kombiniert mehrere Skills,
- definiert Reihenfolge, Rueckspruenge und Endergebnis.

Empfohlene Nutzung:
- Einen Workflow verwenden, wenn mehrere zusammenhaengende Arbeitsschritte als ein konsistenter Ablauf ausgefuehrt werden sollen.
- Fuer Sonderfaelle einzelne Skills aus `../skills/` direkt einsetzen.

## Verfuegbare Workflows

- `analyse-to-issue.md`: Analyseergebnis in ein GitHub-Issue ueberfuehren.
- `bugfix.md`: Fehler untersuchen, beheben und absichern.
- `feature-umsetzung.md`: Feature fachlich und technisch umsetzen.
- `issue-to-pr.md`: Ein einzelnes Ticket bis zur PR-Vorbereitung bearbeiten.
- `issue-umsetzung.md`: Ein bestehendes Issue inklusive relevanter Issue-Beziehungen bis zur versandbereiten Aenderung bearbeiten.
- `refactoring-mit-absicherung.md`: Refactoring mit Analyse, Tests und Review absichern.
