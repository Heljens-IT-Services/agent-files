# Kanonische Heljens-Issue-Templates

## Zweck

Diese Dateien sind die kanonische Quelle für den einheitlichen Heljens-Satz strukturierter GitHub Issue Forms.

## Verbindlicher Satz

Bei der Übernahme werden alle Dateien unverändert nach `.github/ISSUE_TEMPLATE/` kopiert:

- [bug.yml](issue-templates/bug.yml)
- [config.yml](issue-templates/config.yml)
- [epic.yml](issue-templates/epic.yml)
- [refactor.yml](issue-templates/refactor.yml)
- [story.yml](issue-templates/story.yml)
- [task.yml](issue-templates/task.yml)

## Referenzentscheidung

Der Satz entspricht bytegleich den am 18. August 2026 verglichenen Dateien aus `Heljens-IT-Services/building-intelligence` und `Heljens-IT-Services/christ-crs-ui`. `Heljens-IT-Services/heljos` hatte abweichende Fassungen von `config.yml` und `epic.yml`; diese sind nicht kanonisch.
